# v4 参数化路线：各阶段结论与相互制约

本文汇总 v4 四个阶段的**实测结论**，特别是那些「结果不好但是真的」的部分。目的是让下一轮的人（或另一个 agent）不要重复已经踩过的坑，也不要误读某个数字。

## 阶段一：音素对齐（`align.py`）

**结论：在真实数据上不够用，不要指望它提供音素级边界。**

346 个真实音节全量测试：

| 置信度 | 数量 | 占比 |
|---|---|---|
| high | 9 | 2.6% |
| medium | 92 | 26.6% |
| low | 245 | 70.8% |

**一次重要的自我修正**：最初用 14 dB 能量裕度时统计出 77 个 high（22%），看起来能用。逐帧审计发现这些「边界」处的周期性中位数是 `corr = 0.83`——**声带仍在振动**，只是电平低，根本不是阻塞音闭合。裕度提到 30 dB 后只剩 9 个 high。**2.6% 才是诚实的数字。**

结构性不可检测的部分（不是调参数能解决的）：

| 声母类 | n | high% | 说明 |
|---|---|---|---|
| 零声母 | 54 | 0% | 声学上没有「声母/韵母分界」这个事件 |
| 鼻音边音 m n l r | 39 | 0% | 同上，无阻塞音闭合 |

这两类合计 93 条（26.9%）全部 low，且测试里**硬断言它们不得为 high**。任何声称在这两类上能高置信度定位声母边界的实现，都是在伪造。

韵母**内部**过渡切分：high **0 个**（medium 68、low 364）。这是结构性的——当前只有谱带能量变化与能量极小值，没有共振峰轨迹跟踪。要提升必须引入 LPC 极点追踪。

## 阶段二：LPC 共振峰估计（`lpc.py` / `params.py`）

**结论：F1/F2 可用，F3 不可信。**

关键更正：任务描述里的「每位说话人只有 3–6 个片段」是过时信息。语料扩容后实际是：

- 每位说话人 19–20 条整句、325–327 个音节
- 665 个音素 span，其中 286 个产出共振峰估计（43%）
- 37 个韵母中 19 个达到 high（≥5 样本）、4 个 medium、14 个 low

高置信度韵母及其样本数：`i`(35) `u`(20) `e`(20) `ir`(15) `ai`(9) `uo`(9) `en`(8) `ou`(8) `uei`(8) `ao`(7) `ian`(7) `iao`(7) `iou`(7) `v`(7) `in`(6) `an`(5) `iang`(5) `ie`(5) `ing`(5)

### F3 不可信，这是硬结论

在 6 个已知共振峰的合成元音上量系统性偏差（22 阶）：

- F1 偏 −9 ~ −63 Hz
- F2 偏 +38 ~ +215 Hz
- **F3 偏 +158 ~ +420 Hz**

试过两种修法，都如实记录了结果：

1. **升阶数** 18 → 24：F3 平均绝对误差 295 → 169（22 阶）→ 153 Hz（24 阶）**饱和**。采用 22 阶。
2. **高斯 lag window** 40 Hz / 60 Hz：平均绝对误差从 123 Hz **变差**到 125 / 140 Hz。**未采用**。

所以 **F3 偏置无法消除**。`phoneme_params.json` 里的 F3 是「本分析器的测量值」，不是真值。下游 `vocal.py` / `speaker.py` **只应消费 F1/F2**，且都已用测试锁定这一点。

升级到 22 阶的真实收益：`u` 的 F1/F2 是普通话最近的一对（320/780），18 阶时合成 `u` 只有 11/47 帧能估出（极点合并），22 阶 **47/47**；实测语料有共振峰样本 236 → 286。

### 实测与 `synth.py` 通用表的差距

| 韵母 | `synth.V` | 实测 | 差值 |
|---|---|---|---|
| `a` | 790/1300/2650 | 946/1611/2754 | +156 +311 +104 |
| `e` | 470/1220/2700 | 559/1649/3300 | +89 +429 +600 |
| `i` | 285/2200/3050 | 344/2488/3304 | +59 +288 +254 |
| `o` | 490/880/2630 | 452/1056/3653 | −38 +176 +1023 |
| `u` | 320/780/2200 | 398/1030/3449 | +78 +250 +1249 |
| `v` | 310/1770/2490 | 371/2298/3019 | +61 +528 +529 |

**F2 普遍比通用表高 250 ~ 1250 Hz。** 原因不是 bug：这两位说话人 F0 在 207 / 224 Hz，是女声，而 `synth.V` 是偏男声的通用值。这恰好说明用实测替换通用值有实质意义。

## 阶段三：参数化合成器（`vocal.py`）

**结论：等价性链条成立，参数层是唯一变量；但主观音质未知。**

### 强等价断言确实成立

```
空参数表 vs synth.render():  maxdiff 0.0   ndiff 0   len 37992 == 37992
```

**条件**：仅在 `coarticulation=False` 时逐样本相等。开启协同发音后逐样本最大差 0.660，但**长度完全相同**，且后续 unit 的噪声底与基线逐样本一致（有专门测试验证）。

能做到逐比特相等，是因为 `vocal.py` 逐句复刻了 `synth` 的循环——语句顺序、`i % 72 == 0` 控制率、相位回绕、每样本仅一次 `rng.uniform` 抽取。**只 import 不重写是不可能逐样本相等的**，因为随机数消费顺序会变。

### 客观指标

- **F1/F2 确实来自参数表**：47 个段，F1 包络峰值与表内目标误差中位 39.6 Hz、最大 66.8 Hz（F0=152 Hz 时一个谐波就是 152 Hz，已是网格分辨率量级）
- **/a/ 的 F1 极点**：泛型 818.7 Hz → 参数化 837.8 Hz（目标 946.2 Hz）。方向正确，但**只移动了约 1/4 的距离**，原因是单目标路径在整个韵母内保持同一起点、且 F1 带宽较宽。这是已知偏差，测试断言的是「正方向移动 > 15 Hz」，没有声称达到了表内值
- **F3 全程未使用**：`used_formants` 恒为 `["f1","f2"]`；注入 F3=9999 Hz 后输出逐比特不变
- **时长不变**：4 个 unit 与基线样本数逐一相同

### 必须知道的问题（未修复，已记录）

1. **主观音质未知**。开发过程中没有人听过输出，**不声称「更自然了」**。
2. **响度副作用未补偿**：保持 amp 固定、换上实测 F1/F2 后，每音节 RMS 比值为 1.026 ~ 1.238。已逐 unit 记录在 `vocal_01.json`。
3. **擦音亮度只是单个旋钮**，不能还原擦音频谱。实测频谱重心排序是 `s < x < sh < h`，与通用表的 `f < x < sh < s` **不一致**：`/s/` 比原来更暗，`/h/` 碰到下限 0.08 被截断。
4. **`o` 系列无可用实测**（`o` 属 low），`iou/iu/ou/uo/ong/iong` 段级回退；`ei` 是特例：`eh`+`i` 都实测，段级 0 回退，但 `ei` 本身被判 low 而拒绝。
5. **fallback 计数有两个不同含义**：`fallback_segments`（段级，`现在回家？` 为 0）与 `fallbacks`（含 low 韵母整体拒绝，为 1），不要混用。

## 阶段四：少样本说话人参数（`speaker.py`）

**结论：这是一个负结果。说话人缩放模型不如基线。**

留一法交叉验证（36 个片段全部留出各一次，206 个音节参与打分）：

| 指标 | 数值 |
|---|---|
| 模型 median pooled Bark 误差 | 0.6682 |
| 基线 median pooled Bark 误差 | 0.6531 |
| 差值 | **−0.0151 Bark（差 2.31%）** |

### 为什么失败（这才是真正有价值的发现）

**缩放只让预测移动 0.0312 Bark，而未解释的同音素散布是 0.6531 Bark，仅占 4.7%。**

也就是说：在这个语料里，两位说话人的共振峰差异**已经接近噪声底**，标量共振峰缩放没有可加的信息量。

**推论：两位说话人在共振峰上不可分**——F1/F2 距离落在交叉验证误差之内。这与阶段二「两位 F0 只差 207 vs 224 Hz、都是女声」的观察一致。

### 补齐了阶段二的缺口

`spectral_tilt` 在 `phoneme_params.json` 里两位都是 `null`（阶段二没接上这一路）。阶段四从 LTAS 算出来了：

- SSB0502：**−2.71 dB/oct**
- SSB1593：**−4.41 dB/oct**

句间散布很小。**这是整份报告里唯一显示两人可分且超出误差的量**——也就是说，若要区分这两位说话人，谱倾斜比共振峰更有信息量。

### 明确不可用的量（未伪造）

- `f0_holdout`：provenance 里没有逐音节 F0，无法做留出验证
- `bandwidth_scale`：`per_speaker` 里带宽是两人合并存的，无法分开

### 交叉验证样本差异

同句 `现在回家。`、同 seed 的三个 WAV：

- 两位说话人之间最大波形差 **0.0236**
- 与「不加说话人」基线差 **0.38**
- 比值为 **16 倍**

这个数字本身就是负结果的直观体现：换说话人参数几乎不改变波形。

### 方法学说明（易误读）

`formant_scale` 只有**说话人之间的比值**是确定的（0.9837 / 0.9911 ≈ 0.9925）。**单个说话人的绝对尺度无法拟合**，因为参考基准是两人均值，必有一个被基准固定。两位的绝对尺度都 < 1.0，与阶段二的 1.0314 / 1.0270 不同，是因为参考基准不同（阶段二含 F3 且用另一个通用表）。

## 各阶段置信度体系互不相同（容易误读）

- **阶段一**的 confidence = 声母/韵母**边界**检测的可靠性
- **阶段二**的 confidence = 该韵母的**共振峰样本数**（`>=5` high / `3..4` medium / `<3` low），另外叠加「多数样本坐在低置信边界上则降一档」的规则

两者是**独立维度**，阶段二的 `bound_confidence` 统计（665 段中 27 段 low）来自阶段二自己的音节内切分，**不是**阶段一的检测结果。所以阶段二看起来「边界大多 medium」而阶段一报「70.8% low」并不矛盾——它们量的不是同一件事。

**但实践含义是一致的**：阶段一已证明音素级边界不可靠，所以阶段二的共振峰估计**是在较粗的音节级边界内做的**，其误差应视为下限而非上限。

## 下游该怎么用这些结论

1. **不要**假设音素边界准。要按 confidence 分流，low 段回退到音节级参数或直接拒绝。
2. **只用 F1/F2**。F3 有 158~420 Hz 无法消除的系统偏置。
3. **不要**因为 `vocal.py` 通过了等价性测试就认为合成自然度提升了——等价性只证明「改动只来自参数层」，不证明改了之后更好听。
4. 想真正提升音素级精度，需要引入**共振峰轨迹跟踪（LPC 极点追踪）**，这不是调阈值能解决的。
5. **不要**声称已实现音色克隆。当前能证明的最强结论只是：「已从少量样本估计出音色参数，并用留一法量化了误差；量化误差显示两位说话人在共振峰上不可分」。若要区分音色，**谱倾斜（dB/oct）是比共振峰更有希望的描述量**（−2.71 vs −4.41，两人可分）。

## 下一步该往哪走（基于以上负结果）

按性价比排序：

1. **换用谱倾斜作为主要音色描述量**。这是唯一实测可分且超误差的量。共振峰缩放已被证明无效，不要再投入。
2. **引入 LPC 极点追踪做共振峰轨迹**，提升阶段一的音素级边界与阶段二的 /a/ F1 移动幅度（目前只移动了目标距离的 1/4）。
3. **补充更多说话人与更长语料**。两位女声、F0 差 16 Hz 的样本量下，"说话人可分性"这个问题本身就接近不可回答。
4. **实际试听**。全部四个阶段从头到尾**没有任何人听过输出**。在改进自然度之前，必须先有人听，否则无法判断改对了还是改错了。
